# Музеи мира

Статический сайт-каталог: **50 музеев** в 6 регионах (Россия, Европа, Азия, Африка, Австралия, США) и 20 странах. Тёмная тема, поиск музеев на главной странице, адаптивная вёрстка.

## Структура проекта

```
index.html            Главная (генерируется)
russia.html … usa.html  Страницы регионов (генерируются)
404.html              Страница ошибки (генерируется)
css/style.css         Стили
js/main.js            Скрипты (меню, поиск, анимации)
images/               Фото музеев в WebP (1100×733)
favicon.svg           Фавиконка
scripts/
  data/               Данные сайта — ЕДИНСТВЕННЫЙ источник контента
    site.json         Общие настройки и порядок регионов
    <region>.json     По файлу на регион
  build.py            Генератор HTML-страниц из данных
```

## Как изменить контент

Страницы генерируются из `scripts/data/` — правьте данные, а не готовый HTML:

1. Отредактируйте нужный JSON (музей, описание, новый музей).
2. Пересоберите страницы:

```bash
python3 scripts/build.py
```

Новый музей добавляется в массив `museums` файла региона. Поле `image` необязательно задавать вручную, если фото лежит в `images/`. Счётчики на главной (регионы/музеи/страны) и числа на карточках регионов вычисляются автоматически при сборке.

## Деплой

Сайт полностью статический — подойдёт любой хостинг (GitHub Pages, Netlify и т.п.). После деплоя укажите домен в `scripts/data/site.json` → `"url"`, пересоберите: появятся `canonical` и абсолютные `og:url`.

## Работа с изображениями

Фото — WebP 1100×733 (кроп 3:2). Новое изображение можно привести к формату командой:

```bash
magick photo.jpg -resize 1100x733^ -gravity center -extent 1100x733 \
  -strip -quality 78 -define webp:method=6 images/slug.webp
```
